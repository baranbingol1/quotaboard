# QuotaBoard mono icon assets

This folder contains the approved monochrome QuotaBoard QB monogram, prepared with a transparent background and the app's charcoal color (`#171A1C`). No application or project configuration has been changed.

## Files

- `quotaboard-mono.ico` — multi-resolution Windows icon containing 16, 20, 24, 32, 40, 48, 64, 96, 128, and 256 px frames.
- `quotaboard-mono-master-1024.png` — transparent high-resolution raster master with a 12.5% safe area.
- `quotaboard-mono-{size}.png` — transparent exact-size PNGs for common Windows scale factors, from 16 through 512 px.
- `asset-manifest.json` — source selection, included sizes, and validation metadata.

Microsoft recommends providing at least 16, 24, 32, 48, and 256 px assets and prefers exact-size matches to runtime scaling: <https://learn.microsoft.com/windows/apps/design/iconography/app-icon-construction>
