# Security Policy

## Supported versions

Only the latest QuotaBoard release receives security fixes.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/baranbingol1/quotaboard/security/advisories/new).
Do not report an unpatched vulnerability in a public issue.

Include the affected version, reproduction steps, impact, and any suggested
fix. Do not include real provider credentials, session data, or access tokens.

## Release verification

QuotaBoard releases are unsigned. Download them only from the official
[GitHub Releases page](https://github.com/baranbingol1/quotaboard/releases).
Each release includes SHA-256 checksums, an SPDX SBOM, and GitHub build
provenance attestations.
